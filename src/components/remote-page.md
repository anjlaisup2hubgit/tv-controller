# Remote page (page 1)
**Feature:** main remote.
- Volume and list rockers, HOME / MENU / SOURCE, TV / 123 / EXIT.
- D-pad: 4 SVG wedges (UP/DOWN/LEFT/RIGHT) + OK circle, corner keys INFO, OPT., BACK, GUIDE.
- SEARCH, ASPECT RATIO, SETTINGS, colour keys (red/green/yellow/blue).
- Every button sends its `data-key` via `POST /api/key`. Some keys are unsupported on some brands (see `drivers.py`).
