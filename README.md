The remote works with Android TV (which covers Sony, Philips, TCL, Hisense and Xiaomi), Roku, Samsung (2016 and later) and LG webOS. 
Kogan and Roku tv were tested. Samsung and LG are untested.

Run in terminal "cd 'C://directory/of/this/project'"
Run in terminal "python src/server.py"
It will print "http://YOUR-LAN-IP:3000"
Alternatively, ask an AI to host it for you and run "http://localhost:3000/" to see the web's features though the functionalities will not work because a LAN connection is neccessary.
Make sure the device is on the same Wi-Fi as the TV, and copy paste the link in any browser on any device.

Some buttons have no functionality, this is normal.
